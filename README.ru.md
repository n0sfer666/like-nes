# like-nes

[English](README.md) · Русский

2D-игровой движок на C++20 для игр, которым важно **хорошо работать**, а не быстро начаться, — для
тех, где всё решают время кадра, время загрузки и место на диске. Это только движок: завод по
сборке игры, без встроенных редакторов музыки и картинок.

![Образец-сайдскроллер: корабль игрока, враги, счёт и всплывшее достижение](docs/images/sample-game.png)

*Игра-образец, отрисованная самим движком: `game_sidescroller --demo <каталог> --frames 240` пишет
те же кадры headless — этот снят именно так.*

## Чем он отличается

- **Детерминизм — свойство, а не намерение.** Симуляция сверяется с golden-хешами, и один и тот же
  хеш требуется в Debug и в Release: расхождение между уровнями оптимизации в целочисленной
  арифметике — это undefined behaviour, а не «погрешность». Тот же голден держится на разных ОС и
  разных компиляторах — без этого детерминированный сетевой код (rollback с потоком реплея)
  невозможен в принципе.
- **Оптимизация заложена в архитектуру.** Ассеты пекутся в бандл заранее и **байт в байт
  воспроизводимо** — именно поэтому сторонние зависимости пиннуты на коммит и не правятся.
  Рендер идёт через WebGPU (wgpu-native): Metal на macOS, Vulkan на Linux, DX12 на Windows.
- **Свободный, без оговорок.** `MIT OR Apache-2.0` на выбор. Ни роялти, ни порогов выручки, ни
  ограничений на коммерческое использование: игры, собранные на движке, целиком принадлежат своим
  авторам и распространяются на любых условиях, включая проприетарные.
- **Три десктопных ОС — один продукт.** Каждый гейт гоняется на macOS, Linux и Windows в CI, а
  платформенный код заперт в именованном шве, а не размазан по дереву.

## Статус

**В разработке. Релиза пока нет.** Из 22 спек роадмапа закрыты 17 — с принятым ADR; остальные в
работе. Публичный API меняется без предупреждения и будет меняться до первого тега релиза.

Что уже есть и проверяется гейтами на всех трёх ОС: ядро ECS и фиксированный тик, пекарь ассетов и
формат бандла, ввод с перебиндами, 2D-физика, контроллер персонажа и тайлмапы, спрайты, анимация,
камера и частицы, материалы и шейдеры, аудио, плагины (нативные и WebAssembly), достижения,
hot-reload, оболочка редактора и детерминированная сеть.

## Быстрый старт

```sh
git clone https://github.com/n0sfer666/like-nes.git
cd like-nes
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/editor_shell          # Windows: build\editor_shell.exe
```

На Windows это запускается из *x64 Native Tools Command Prompt for VS*: в обычной оболочке нет
`cl.exe`, а 32-разрядный developer prompt отвергается намеренно. Что должно быть установлено на
каждой ОС и как выглядит отказ — в [руководстве по началу работы](docs/ru/getting-started/prerequisites.md).
