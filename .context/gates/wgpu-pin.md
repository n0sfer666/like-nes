# Пин wgpu-native по релизу upstream (аудит #21 A·3·2, A·3·15)

```
bash scripts/check_wgpu_pin.sh [<build>]   # фикстуры + настоящий блоб сконфигурированного каталога
```

Главная проверка — само конфигурирование: [`cmake/wgpu_native_check.cmake`](../../cmake/wgpu_native_check.cmake)
сразу после `FetchContent_MakeAvailable(webgpu)` зовёт функцию из
[`cmake/wgpu_native_pin.cmake`](../../cmake/wgpu_native_pin.cmake) (её же берут фикстуры), и та сверяет `file(SHA256)` блоба своей тройки
(`WGPU_RUNTIME_LIB`, на Windows ещё и `.dll.lib`) с [`cmake/wgpu_native.sha256`](../../cmake/wgpu_native.sha256).
Расхождение или тройка без суммы → `FATAL_ERROR`. Значит, каждый Configure в CI сверяет блоб
Linux, macOS и Windows без отдельного шага.

- **Зачем.** `libwgpu_native` — единственный чужой нативный код, который пакет ставит пользователю,
  а приезжает он из личного репозитория `eliemichel/WebGPU-distribution` (коммит `ac055bef`,
  «wgpu-v0.19.4.1 + fix»). Git-пин даёт целостность, но не происхождение.
- **Откуда суммы.** 2026-09-25 сняты потоком с артефактов релиза `gfx-rs/wgpu-native` v0.19.4.1
  (`wgpu-<тройка>-release.zip`, файл внутри архива) и сравнены с блобами форка: совпали побайтно
  все шесть (macOS ×2, Linux ×2, Windows x86_64 dll + import lib). «+ fix» форка касается
  `webgpu.hpp`, не бинарей.
- **A·3·15** (рукописный `git fetch` в транзитивном `webgpu.cmake`) закрыт этим же: сверяется
  конечный файл, способ доставки перестаёт быть важен для происхождения.
- Пустой `WGPU_RUNTIME_LIB` даёт ключ `/` → «не пиннут» → FATAL: вакуумно зелёной сверка стать не
  может.

Кейсы (6 + 1): пиннутая сумма принята, изменённый байт → отказ, та же сумма под другой тройкой →
отказ, ключ сравнивается целиком (не хвостом), нет файла, пиннутый, но отсутствующий файл; плюс
настоящий блоб из `<build>/CMakeCache.txt`, если каталог сконфигурирован. Негативный контроль:
сверка-заглушка (поведение до A·3·2) — 5 FAIL.

Смена версии wgpu: новые суммы с артефактов релиза upstream в `wgpu_native.sha256` тем же
коммитом, что и пин `webgpu`, иначе конфигурирование упадёт — так и задумано. Переезд меняет
рендер-выход — перештамповать голдены кадра (regression_risk находки).
