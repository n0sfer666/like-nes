# Симуляция драки без float — `scripts/check_sim_float.py`

```
python3 scripts/check_sim_float.py             # блокирующий гейт, в checks.json
python3 scripts/check_sim_float.py --selftest  # 32 контроля на фикстурах
```

Спека #25, нефункциональные: симуляция — только fix32 и целые. Хеш кроссплея сверяется между
тремя ОС, и одно `float` в шаге даёт расхождение, которое назовёт джоб `crossplay`, но не причину.
Гейт называет причину строкой.

- **Где.** `engine/framework/{brawl,ai,scene,touch}` — файлы глазами `git ls-files --cached --others
  --exclude-standard`, расширения C/C++. `ai` — с В5, `scene` — с В6а
  (2026-10-11): `float leak;` в конце `scene_objects.hpp` → FAIL, строка 94; откат — PASS, 120 файлов.
  `touch` — со спеки #26 В2б (2026-10-16): ось экранного стика уходит в InputFrame и в sim-хеш, а
  оболочки отдают float. `float leak;` в конце `touch_source.hpp` → FAIL, строка 68; откат — PASS,
  247 файлов. `games/neon-rumble/sim` — со спеки #29 В2а (2026-10-29): симуляция игры уходит из
  SDK в игру, и гейт идёт за ней. Список — `SIM_PATHS`, каталог или файл: путь в обходе, если равен
  записи или лежит под ней (`simx/` соседнего каталога — нет; семь контролей `путь — …`, три из них — на файловой записи:
  сама в обходе, сосед по каталогу и продолжение имени — нет). Запись, не нашедшая ни одного
  файла, — отказ гейта (`охранник — запись SIM_PATHS без файлов`): опечатка или переезд файла иначе
  молча выкидывал ядро из обхода, а порог `MIN_FILES` перекрывали остальные каталоги. Удалённый
  каталог уходит из `SIM_PATHS` тем же коммитом. Контроль 2026-10-29: `seats.hpp` → `seat.hpp` в
  `SIM_PATHS` → FAIL с именем записи; `under` без равенства → FAIL `путь — файловая запись в обходе`.
  `float leak;` в конце `rumble_floor.cpp` → FAIL, строка 23; откат — PASS, 252 файла. Ядра, вынесенные
  из жанра в общие каталоги SDK (спека #29 В2б), — файлами поимённо: в `core/` и `physics/` float
  законно стоит в тестах и единицах, а новые каталоги ядер (`depth`, `hits`, `kinematic`) — целиком.
  `core/{ent_id,world_rng,seats}`, `physics/seat_hash` (2026-10-29): `float leak;` в конце
  `seat_hash.cpp` → FAIL, строка 30; откат — PASS, 252 файла.
  `input/{flick,action_buffer}` (2026-10-29): `float leak;` в конце `flick.cpp` → FAIL, строка 28, и
  `action_buffer.hpp` → FAIL, строка 32; откат — PASS, 253 файла.
  `physics/pendulum` (2026-10-29, `brawl/rope_swing.cpp` переехал туда же): `float leak;` в конце
  `pendulum.cpp` → FAIL, строка 38, и `pendulum.hpp` → FAIL, строка 34; откат — PASS, 254 файла.
- **Что.** Три правила. Типы и конверсии словом целиком: `float`, `double`, `float_t`, `double_t`,
  `_FloatN`, `floatN_t`, а также `from_float` и `to_double` из `fixed.hpp` — они для границ
  (авторинг, рендер), не для шага; `long double` — одна находка. Плавающие литералы: `0.5`, `1.f`,
  `.5`, `1e3`, hex-float `0x1.8p3`; `0x1e3`, `1'000` и точка члена (`arr[0].y`) — не литералы.
  `#include <cmath>` / `<math.h>`.
- **Что не в счёт.** Комментарии (`//`, `/* */`) и строковые/символьные литералы гасятся до поиска;
  переводы строк сохраняются, номер строки находки точный. Апостроф после цифры или hex-буквы —
  разделитель разрядов (`1'000`), а не начало символьного литерала: иначе `1'000; float f = 2'0;`
  прятал бы код между апострофами (та же ловушка, что у `hash-seam`).
- **Охранники** (отказ, а не «находок нет»): в обходе нет `engine/framework/brawl/`; файлов меньше 10;
  ни в одном файле нет `fix32` вне комментариев — значит, разбор сломан.
- **Предел.** Сырые строки `R"(...)"`, макросы, склеивающие токен (`fl##oat`), и `#include "math.h"`
  в кавычках не разбираются; плавающий тип, пришедший через `auto` из чужого заголовка, не виден.

Самопроверка гоняется и перед гейтом (`selftest(verbose=False)`): сломанное правило молчит так же,
как чистое дерево. В CI — `--selftest` на трёх ОС, гейт — на Linux (`ci.yml`, рядом с hash-seam).
