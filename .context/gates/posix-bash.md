# Выбор bash на швах процесса — `scripts/posix_bash.py`

```
python3 scripts/posix_bash_selftest.py   # заглушка-мост в PATH: правила на сломанных кандидатах
```

Python, зовущий шелл по ИМЕНИ, получает первый `bash` из PATH, а на windows-раннере GitHub первым
там стоит `C:\Windows\System32\bash.exe` — **мост в WSL, а не шелл**. Без установленного
дистрибутива он печатает своё сообщение в UTF-16 и возвращает 1, и 2026-09-06 самопроверка врезок
прочитала одиннадцать строк «Windows Subsystem for Linux has no installed distributions» как
одиннадцать документов дерева: отказ выглядел оборвавшимся обходом `docs/`, которого не было вовсе.
Диагноз держался ровно до того прогона, где контроль напечатал сам полученный список.

- **Кандидат выбирается ОТВЕТОМ, а не наличием имени в PATH** — то же решение, по которому
  `check_release_container.sh` выбирает движок ответом `info`, а не наличием бинаря. Перебираются
  ВСЕ `bash` из PATH (под Windows — по PATHEXT-набору имён), первый ответивший пробой и берётся.
- **Судится вывод ВМЕСТЕ с кодом возврата.** Мост возвращает единицу и печатает своё; «код ноль»
  порознь принял бы за шелл всё, что молча завершается, а «напечатал слово» порознь — то, что
  печатает и падает. Обе половины держат свои кейсы.
- **Проба спрашивает про файловую систему ХОСТА**, а не только про умение исполнить `-c`: мост с
  УСТАНОВЛЕННЫМ дистрибутивом `printf` отработает и вернёт мусор на windows-путь, который ему потом
  отдадут в `cwd`. Файл-маркер лежит в каталоге хоста, и linux-сторона моста его не видит.
- **Не ответил ни один — ОТКАЗ со списком проверенных И ПРИЧИН**, а не молчаливый откат на строку
  `"bash"`: откат вернул бы ровно тот мост, ради которого модуль и заведён, а отказ без причин по
  кандидатам восстанавливается на чужом раннере ровно ничем — неверный диагноз этой же порчи стоил
  четырёх прогонов CI. Поэтому и порчи требуют ПОДСТРОКИ в тексте отказа, а не только его факта.
- **Заглушка, которую перебор не ВИДИТ или не ЗАПУСКАЕТ, читается как «выбор её отбил»**: кейс
  «в PATH только мост» отказал бы тогда по причине соседнего — «ни одного кандидата» — или по
  невозможности запуска, ничего не сказав об ответе. Поэтому и видимость подставленного кандидата,
  и его запуск (честная заглушка, печатающая слово пробы, обязана быть ВЫБРАНА) утверждаются
  отдельно, до порч. Контролей девять: 5 опорных `pass` и 4 отбитых кандидата.
- Самопроверка идёт **на всех трёх ОС** и ПЕРЕД набором врезок, который этим выбором пользуется:
  сам гейт видит лишь исход выбора, а порча живёт только здесь. Ветвление по ОС внутри фикстуры
  предметно и неизбежно: на Windows исполняемым кандидатом может быть только файл из PATHEXT —
  настоящий PE фикстуре взять негде.
