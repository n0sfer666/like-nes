# SDK без жанра — `scripts/check_sdk_genre.py`

Коммит-гейт #29 В2е: `python3 scripts/check_sdk_genre.py`, правила — `--selftest`.
Источник — единственный `set(LIKE_NES_SDK_HEADERS …)` из `cmake/sdk_headers.cmake` и тексты
перечисленных заголовков в `engine/`. Пустой/непонятный список, дубли, меньше100 заголовков и
отсутствующий файл дают отказ; обход всего дерева не подменяет публичный интерфейс SDK.

Запрещены пути `framework/brawl/`, `framework/ai/` и заголовки кита в
`framework/character/`: controller, assist, ladder, profile* и trajectory. Собственно кит
живёт вне SDK в `games/kits/platformer/`; геометрическое ядро character остаётся в SDK.

Проверяются также имена файлов и идентификаторы C++ после удаления комментариев и литералов
общим `cpp_text.split_code_comments`. Разбиение snake_case/CamelCase/ACRONYMCase не зависит от
регистра. Сравниваются целые токены и формы без окончаний s/es; подстрока `wave` в `waveform`
не считается словом. Пара attack+token должна встретиться в одном идентификаторе или имени
файла: отдельные общие имена attack и token не означают менеджер боевых жетонов.

| Токен | Почему принадлежит игре |
|---|---|
| brawl | цикл драки и её мир |
| fighter | профиль, таблица и сущность бойца |
| archetype | архетип бойца |
| wave | волна врагов и её прогресс |
| checkpoint | игровой прогресс уровня |
| grip | захват бойца |
| strike | игровой удар |
| combo | цепочка атак |
| knock | реакция бойца на удар |
| attack+token | выдача жетонов атак игровому ИИ |

Arena остаётся общим словом (render/arena, TargetArena). Ladder/controller не запрещены как
токены: TILE_LADDER и MoveState::Ladder — известная часть общего состояния. Кит ловится путями.
Allowlist нет: на публичных заголовках после В2д находок не было.

Selftest: 16 контролей — обязательные сломанные waves, brawl path, FighterTable и controller;
дополнительно ai path, profile, имя checkpoints и AttackTokens. Чистые контроли — TargetArena,
waveform, комментарии/литералы и два независимых общих слова. Алиасы через `.`, `..`, абсолютный
путь и регистр тоже отбиваются. Перед чтением гейт отказывает неканоническому пути и ссылке,
меняющей адрес источника. Selftest запускается и перед
обычным гейтом: сломанные правила не могут выдать зелёный результат.
