# #26 В4: роль LIKENES_SAVE_DIR

Решение владельца, 2026-11-02, интерактивное интервью:

> Сохранить LIKENES_SAVE_DIR как явный абсолютный override на десктопе; на мобилках приоритет у каталога оболочки, перенос нужен при различии путей.

Порядок: явно заданный platform::set_save_dir (включая пустой отказ), затем непустой абсолютный
LIKENES_SAVE_DIR, иначе user_data_dir(app). Относительный/недоступный override не разрешает
fallback к другому месту. Legacy-перенос не перезаписывает существующие файлы назначения.

Следствие для изоляции: выбирается один прежний источник по старому приоритету. Наличие
явного env не разрешает читать и переносить профили из обычного OS/exe-каталога в override.
