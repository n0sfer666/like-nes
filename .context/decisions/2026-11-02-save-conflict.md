# #26 В4: равные счётчики разных сейвов

Решение владельца, 2026-11-02, интерактивное интервью:

> Сохранить обе и вернуть Conflict (рекомендую): игра явно решит конфликт, данные не теряются.

Больший счётчик по-прежнему выбирает копию без участия часов. При равных счётчиках одинаковое
содержимое не является конфликтом; разное не получает автоматического победителя. Обе копии
сохраняются, API возвращает Conflict. Экран разрешения — потребитель (пилот), не SDK.
Решение добавлено в спецификацию #26; контейнер/Backend реализуются следующей частью В4.
