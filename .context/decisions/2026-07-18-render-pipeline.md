# ADR 0002: Архитектура рендер-пайплайна (2D, Hollow-Knight-уровень)

- **Дата:** 2026-07-18
- **Статус:** **Accepted** (2026-07-18) — validation gate пройден render-вертикалью PoC (T4).
- **Контекст:** [спека #2](../specs/2026-07-18-render-pipeline.md); наследует [ADR 0001](2026-07-18-language-and-core.md).

## Проблема

Дать 2D-графику уровня Hollow Knight (нормал-мапленный свет, пост-процессинг, партиклы,
спецэффекты) при приоритете №1 (оптимизация RAM/CPU/GPU), цель №1 — Steam-десктоп, мобилки
через tiers, потолок топ-эффектов — без ограничения WebGPU.

## Решения

| Аспект | Выбор |
|---|---|
| Освещение | **hybrid**: deferred-2D для непрозрачных + **forward-пасс для прозрачных** (HK = alpha-спрайты); tiled-clustered forward tier (мобилки); нормал-мапы |
| Сабмишн | GPU-driven (indirect + compute culling) |
| Пост-процесс | композируемый render-graph |
| Партиклы | GPU compute, визуал-only (не кормят сим) |
| Цвет | линейный HDR (десктоп) / sRGB (мобилки) + тонмаппинг |
| Планы | layer-система + render targets по слоям |
| Шейдеры | WGSL + material-система; hybrid offline(релиз)/рантайм(редактор); WGSL→SPIR-V (Tint/naga) |
| Текст | SDF + растровый CJK-fallback |
| Разрешение | виртуальное + режимы (pixel-perfect / smooth) |
| RHI | render-graph-центричный = **render-часть HAL спеки #1** (не отдельный слой); backend'ы: WebGPU (сейчас) + native Vulkan + console (позже) |

## Ключевой tradeoff — scope и фазирование

Все выборы — «максимальные». В сумме это рендерер AAA-масштаба, что трётся о «минималистичный
движок» и «оптимизация без танцев с бубном» (два backend'а = танцы). Research: шипперы берут
нативный Vulkan только упершись в потолок (Tiny Glade).

**Решение по scope:** проектируем архитектуру под всё (RHI-граница, tier-абстракции сразу), но
**реализуем desktop-first вертикалью на WebGPU**. Нативный Vulkan-backend и мобильные tiers
вставляются в готовые точки расширения позже. Философия walking-skeleton (проектируй под всё,
строй критический путь первым) — она сработала в спеке #1.

> ⚠️ **Честная рекомендация владельцу зафиксирована:** не строить два backend'а до наличия
> контента — это преждевременная сложность. Владелец выбрал «RHI под два» осознанно; реализация
> Vulkan отложена фазированием.

## Условия финализации (validation gate) — ✅ ПРОЙДЕН

Proposed → Accepted когда render-вертикаль PoC (T4) закрывает риск освещения:
1. ✅ Непрозрачный нормал-мапленный спрайт (deferred-2D) **+ прозрачный спрайт через forward-пасс**
   (валидирует шов lighting-technique) + 3 динамических света на WebGPU/Metal-десктопе — на экране.
2. ✅ Линейный HDR (rgba16float) + bloom (render-graph, аренный пул) + ACES-тонмаппинг.
3. ✅ **Epsilon/perceptual golden-image** (offscreen, Metal-эталон на пиннутой машине) зелёный —
   НЕ побайтовый хеш; негативный тест подтвердил, что гейт ловит регрессии.

**PoC:** `poc/render/` (см. [спеку #2](../specs/2026-07-18-render-pipeline.md) → «Тестовая стратегия»);
target'ы `render_demo` (окно) / `render_golden` (headless T4). Инварианты соблюдены: «GPU не
кормит сим» (readback только в файл/тест), транзитные таргеты через аренный пул (allocs стабильны,
без per-frame heap). Honest-limit: committed-golden пиннут на Metal этой машины; портируемый
lavapipe-golden для cross-machine CI — follow-up (open Q #6). RHI↔Vulkan-шов остаётся open Q #3.

## Последствия

- Материалы/шейдеры пишутся раз, компилируются под активную lighting-technique и оба backend'а.
- Ассет-пайплайн (спека #1) расширяется: кеш скомпилированных шейдеров (WGSL/SPIR-V).
- Offscreen-рендер для CI закрывает и render-хвост спеки #1 (headless golden-image).
- Node-редактор материалов и мобильные tiers — отдельные задачи/плагины позже.
