# Music manifest: именованный fade_ms

Решение владельца2026-11-03, принято в интервью В6. Необязательный именованный суффикс
fade_ms=N можно задать без точек лупа; по умолчанию1000мс.

Грамматика: music|<name>|vorbis|<path>.ogg[|<loop_start>|<loop_end>][|fade_ms=N].
Суффикс последний, пара точек лупа остаётся необязательной. Это снимает противоречие #26:
кроссфейд должен задаваться манифестом, но первоначальная грамматика называла только loop pair.

Часть В6б1 добавляет метаданные и проверенный источник MusicSrc; фактический Ogg import
и разбор этой грамматики реализуются следующей единицей В6.
