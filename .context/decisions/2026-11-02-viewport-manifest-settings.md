# В2е #29: настройки viewport из манифеста

Интервью владельца 2026-11-02:

1. Доставка — необязательная секция бандла. При стандартных размерах секция не создаётся,
   текущий bundle.hash сохраняется. Нестандартные размеры игра читает из бандла.
2. Это общий API SDK: парсер, формат секции и проверка покрытия общие для игр. Игра явно
   загружает настройки и передаёт их своему миру; игровые правила камеры принадлежат игре.

Повторный ответ на ранее открытое async-интервью подтверждает пункт1.

План реализации: общие ViewportSettings и reader/baker → директивы zone/zone_limit в манифесте
и проверка покрытия теми же размерами → необязательная секция viewport → явное чтение игрой,
проводка в BrawlWorld, симуляцию, рендер desktop/mobile и отчёты → unit/refusal/сломанные
контроли, сравнение прежних голденов и bundle.hash, SDK-пакеты, независимое ревью.

Детали реализации делегированы владельцем: строки `zone | <w> | <h>` и `zone_limit | <w> | <h>`,
одна настройка каждого вида на манифест; размеры — положительные целые до32767 (помещаются
в целую часть fix32). Ошибки — отказ с номером строки. Меньший зоны limit трактуется так же,
как уже реализованные общие viewport/coverage API: эффективный предел не меньше зоны.
