# #26 В4: перенос в карантин через Backend

Решение владельца, 2026-11-02, интерактивное интервью:

> Добавить move_new (рекомендую): перенос без перезаписи; при ошибке исходник сохраняется. LocalBackend реализует файловую операцию.

Шов Backend расширяется с read/write/list до read/write/list/move_new. Проверка «свободно»
и последующая обычная перезапись не удовлетворяют контракту: существующий карантин сохраняется.
Реализация LocalBackend и fake-backend тесты входят в оставшуюся часть В4; В4а даёт только
общий атомарный writer. Этот файл фиксирует решение, не утверждает готовность move_new.
