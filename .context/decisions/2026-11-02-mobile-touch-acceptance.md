# Приёмка мобильного тача перед В3

Решение владельца 2026-11-02, ответ на интервью о физической проверке раскладки:

> сначала проверить в эмуляторе. критерий сдачи - персонаж двигается и атакует при помощи тапов по виртуальным падом

Ближайший критерий — живой эмулятор: настоящий MobileRumble двигает персонажа и запускает
атаки от экранного стика/кнопок, без demo. Проверка source ownership, CPU pipeline, сборка APK,
синтетические логи и отсутствие ошибок сами по себе критерия не закрывают. Нужны живой запуск
и наблюдаемое движение/атака; после этого можно продолжать В3.

Физическая эргономика из прежней В2е остаётся открытой отдельным гейтом владельца§38; отсутствие
телефона больше не является ближайшим блокером В3. Подготовленный en/ru сценарий сохраняется.
Push/PR/merge этим решением не разрешены.

## Результат

2026-11-02 владелец проверил настоящий Neon Rumble без demo в Device Hub, iOS27 simulator,
и ответил: «Персонаж двигается и атакует». Согласованный ближайший критерий перед В3 закрыт
живой проверкой владельца. Агент установил свежий пакет и наблюдал сцену/вход P1; его
GUI-свайпы не дали надёжного автоматического доказательства. Это не PASS полного автогейта
двух пальцев/двух landscape, Android SwiftShader или физической эргономики. Следующий этап — В3.
