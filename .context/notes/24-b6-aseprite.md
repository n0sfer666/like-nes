# Спека #24, В6 — рабочие заметки (состояние между сессиями)

## Факты о реальном паке (2026-10-02)

Chewbatrij «Beat em Up Graphics Pack», OpenGameArt, CC0, `punchingqueen_gfx.zip`
sha256 `76c4a4ad8c2af1a81d0314b1fee60fd8d155dcc18227aa126b34642596dba4c7`
(https://opengameart.org/sites/default/files/punchingqueen_gfx.zip).

- Экспорт Aseprite **1.2.8**, `frames` — **hash** (ключи `Queen 0.ase`…), не array.
- **Slices нет** ни в одном JSON и ни в одном `.ase` (чанк 0x2022 отсутствует); user data тегов нет.
- Теги пересекаются (`Death` 3–8 ⊃ `Hit` 3–3), в именах `+` (`Walk+Knuckles`); trim нигде;
  длительности все 100 мс. `meta.image` — абсолютный Windows-путь (игнорировать).
- `queen.json` 29 кадров, 20 тегов, лист 2146×75; `fistbot.json` 5 кадров, 3 тега.

## Решения владельца (опрос 2026-10-02)

1. Фикстура: `queen.json`/`queen.png` 1.2.8 — реальная фикстура кадров и тегов; боксы и события —
   на рукописном JSON в форме 1.3. Владелец размечает `Queen.ase` в Aseprite 1.3 (hit на кадрах 3–4,
   событие в user data тега) и экспортирует — новый шаг owner-verification (как Tiled в §18).
   Запасной путь `ev:<имя>` — только если реальный экспорт этого потребует.
2. `frames`: принимать **array и hash**; у hash порядок кадров = порядок ключей в файле.
3. Клип = тег; пересекающиеся теги допустимы, у каждого клипа своя копия кадров; ключи slices
   считаются отдельно в пределах каждого клипа.
4. Два коммита: В6а — бейк (разбор Aseprite и `.sheet`, `LNCL`, читатель-валидатор, запись `clips`
   в манифесте, fuzz `clips` +1 в пяти местах, голден Aseprite = `.sheet`, лицензия пака);
   В6б — рантайм (`frame_boxes`, боец в Neon Rumble, боксы на F3, пиксельный голден).

## В6а — решения по ходу


- **Строка клипа несёт guid текстуры листа** (`ClipRow::texture_guid`), регион кадра — индекс
  кадра в клипе, прямоугольник и якорь — в `ClipCel`. Имена событий — таблица клипа, `AnimEvent` —
  индекс с 1 (0 = `ANIM_EVENT_NONE`).
- **Лист Aseprite** — basename `meta.image` рядом с JSON (абсолютный Windows-путь 1.2.8 не
  читается), размер обязан совпасть с `meta.size` и с записью `texture` манифеста.
- **`.sheet`** — строка `image|<png>` первой, `#`-комментарии; номера кадров у `box`/`event` — в
  порядке ПРОИГРЫВАНИЯ, боксы — относительно пивота (низ-центр клетки). У Aseprite номер события —
  от первого кадра тега в порядке ФАЙЛА (спека), разворот `reverse` уносит событие вместе с кадром.
  Текст события обрезается по обе стороны `:` (`" 0 : step "`).
- **`repeat` и пинг-понг** (ревью В6а, сверено с `doc/playback.cpp` Aseprite): каждый проход
  пинг-понга — один повтор. `"1"` + `pingpong` → `CLIP_ONCE` без `CLIP_PINGPONG` (один проход,
  `pingpong_reverse` — назад); `"2"` и больше — отказ, в том числе у пинг-понга: одноразовый
  пинг-понг движка кончается на кадре 1, Aseprite — на кадре 0.
- **Признаки флагов экспорта**: первый номер не 0 → `--ignore-empty`/`--frame-range`; `meta.scale`
  не `"1"` → `--scale`; пропуск номера в имени кадра → `--ignore-empty`; повтор номера →
  `--split-layers/--split-tags`; две записи на одну клетку листа → `--merge-duplicates`.
- **Ключ slice до начала тега в тег не переходит** (решение 3): клип начинается без бокса, пока
  внутри тега нет своего ключа; пивот без ключа — низ-центр.
- **`framework_graphics_import`** (`import.cmake`) — отдельная цель ВНЕ SDK: тянет `framework_json`
  через `framework_tiled` и переиспользует `tiled::Doc`/`tiled::Source` без рефакторинга. Вынос `Doc`
  в общий модуль — вариант на будущее, если третий импортёр его потребует. В SDK — только
  `clip_format/clip_bake/clip_read`.
- **queen.png 2146 px > 2048** — в `game.manifest` королева в В6а не идёт; фикстура теста импорта
  читает её из `games/neon-rumble/assets/chewbatrij/` (в инвентаре лицензий, CC0). Для В6б —
  переэкспорт By Rows владельцем (§19 owner-verification) или запись листа рядами.
- **Ручной шаг владельца** — §19 `docs/owner-verification.md` + `scripts/aseprite_owner_check.sh
  <каталог>`: разметка Queen.ase в 1.3 (hit0 на кадрах 3–4, user data `Death` = `1:fall`), бейк
  поставленным `assetc`, затем `clip_dump` (`tools/assetc`) печатает таблицу из бандла, и скрипт
  ищет четыре строки исхода; контроли — синтетический экспорт с разметкой (PASS) и без (FAIL);
  присланный `queen.json` станет фикстурой.
- **Ошибка пекаря клипов** адресуется своей записи: `check_clips` зовётся на каждую запись
  `clips` манифеста, строка общей таблицы остаётся только у отказа `finish` (> 4 ГиБ).
- **`.sheet`-бокс** обязан лежать в клетке: x ∈ [−w/2, w − w/2], y ∈ [−h, 0] от пивота низ-центр.
- **Пользовательская документация** формата `clips`/`.sheet` — вместе с остальным манифестом в В8
  (DoD раунда п. 6): в `docs/en|ru` манифеста пока нет вовсе, писать половину раздела — хуже.

## В6б — решения по ходу (2026-10-03)

- **Лист рядами** — `chewbatrij/queen-rows.*` сделан скриптом перекладки (клетка 74×75, 8 в ряд):
  PNG без фильтров, в JSON переписаны `frame`, `meta.image`, `meta.size`; хеши в инвентаре.
- **Имя записи уникально в манифесте** между видами: лист — `queen_sheet`, клипы — `queen`.
- **sRGB и тинт**: `QuadRenderer` умножает выборку на тинт без линеаризации, поэтому на sRGB-цели
  тинт 0x80 светлее, чем на unorm. Оверлей держится каналов 0/255; чинить шейдер — отдельная задача.
- **F3 опросом `glfwGetKey`** — как в `framework_input_probe`; синтетическое нажатие короче кадра
  теряется (smoke держит клавишу 120 мс через CGEvent). Фронты клавиш — с управлением в #25.
- **Мутанты голдена**: LOOP → PINGPONG выживал, пока вид флипа стоял внутри первого периода —
  перенесён на тик 14; «бокс не того вида» в пикселях невидим (проход Hurt перекрашивает рамку) —
  его убивает `clip_read_test`.
- **`sdk-game --keep`** не чистил `build-sdk-work/prefix`: `cmake --install` только добавляет, и
  заголовки, убранные из SDK (`layer_quads.hpp` в `framework/graphics/`, `section_open/format.hpp` в
  `tilemap/`), оставались и перекрывали новые. Починено по ревью: прежний префикс уезжает во
  временный каталог прогона (`mv`, не `rm`), SDK ставится в пустой.
