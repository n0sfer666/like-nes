# #26 В6 — музыка

## В6а: resident stereo в Mixer

StereoFrame хранит int16 L/R. register_stereo_source до запуска callbacks заимствует immutable
PCM до уничтожения Mixer после остановки/join callback, также для queued/future play.
Возвращает false на duplicate guid (также mono), full registry,
null PCM с ненулевой длиной; отказ не меняет реестр. Пустой источник — тишина.
Stereo voices не используют spatial pan/attenuation/listener, но сохраняют voice/bus/master
gains, ducking, limiter, loop/start offset, voice pool/stealing. Mono пути сохраняют результат
бит-в-бит. Sample fetch/два mix backend вынесены в mixer_mix.cpp как одна ответственность;
четыре ручных CI compile commands также используют новый TU.
Точные sample-time assertions касаются Play/start offset; старое поведение Stop/SetBus/Master
внутри блока не расширялось (они применяются до mix всего блока).

Голден стерео24a69db0fc56de9f получен независимым Python LE <hh>:256frames,delay47,period5,
без вызова Mixer/Limiter, seed из существующего общего hash.hpp (не стандартный FNV offset).
Happy test сравнивает каждый выходной семпл с заданным PCM, плюс блоки1/17/256/800, старт17,
нециклический конец, gains/clamps, mono reuse. Limits: registry/empty/zeroheap callback с
plain/aligned controls, command drain/voice-stealing, оба backend. CI Release/Debug/SAN.

Это ещё не потоковый MusicStream, stereo ring/generations/fades и music metadata — следующие
единицы В6. audio_core ранее не экспортировался SDK; экспорт будет с MusicStream и его headers.

Allocation/registry limits test находится в tests/audio: он использует общий тестовый
framework_alloc_probe_control, не создавая запрещённого ребра audio→framework.

Решение владельца2026-11-03 для следующей manifest части: необязательный именованный
суффикс fade_ms=N после path либо пары loop_start/loop_end, по умолчанию1000мс.
