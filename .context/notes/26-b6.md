# #26 В6 — музыка

## В6а: resident stereo в Mixer

StereoFrame хранит int16 L/R. register_stereo_source до запуска callbacks заимствует immutable
PCM до уничтожения Mixer после остановки/join callback, также для queued/future play.
Возвращает false на duplicate guid (также mono), full registry,
null PCM с ненулевой длиной; отказ не меняет реестр. Пустой источник — тишина.
Stereo voices не используют spatial pan/attenuation/listener, но сохраняют voice/bus/master
gains, ducking, limiter, loop/start offset, voice pool/stealing. Mono пути сохраняют результат
бит-в-бит. Sample fetch/два mix backend вынесены в mixer_mix.cpp как одна ответственность;
четыре ручных CI compile commands также используют новый TU.
Точные sample-time assertions касаются Play/start offset; старое поведение Stop/SetBus/Master
внутри блока не расширялось (они применяются до mix всего блока).

Голден стерео24a69db0fc56de9f получен независимым Python LE <hh>:256frames,delay47,period5,
без вызова Mixer/Limiter, seed из существующего общего hash.hpp (не стандартный FNV offset).
Happy test сравнивает каждый выходной семпл с заданным PCM, плюс блоки1/17/256/800, старт17,
нециклический конец, gains/clamps, mono reuse. Limits: registry/empty/zeroheap callback с
plain/aligned controls, command drain/voice-stealing, оба backend. CI Release/Debug/SAN.

Это ещё не потоковый MusicStream, stereo ring/generations/fades и music metadata — следующие
единицы В6. audio_core пока не экспортируется SDK; экспорт нужен следующему Ogg import/MusicStream.

Allocation/registry limits test находится в tests/audio: он использует общий тестовый
framework_alloc_probe_control, не создавая запрещённого ребра audio→framework.

Решение владельца2026-11-03 для следующей manifest части: необязательный именованный
суффикс fade_ms=N после path либо пары loop_start/loop_end, по умолчанию1000мс.
Можно задать fade без явных точек лупа; полная грамматика будет уточнена вместе с пекарем.

## В6б2: Vorbis reader и реальная гонка CRC

VorbisReader — borrowed immutable encoded span до close/destroy, один поток на экземпляр,
разные экземпляры параллельно. Open/length/seek сериализованы вне RT: pinned stb_vorbis
при каждом open пишет global crc_table, length/seek её читают. Sequential read CRC не использует.
Vendor pin не менялся. Лимит каналов16 задаётся одним CMake значением для C/C++ TU.
Read принимает native channels либо2; stereo→mono внутри pinned C API небезопасен (assert/OOB),
поэтому downmix остаётся собственным int32 average в decode_vorbis. Неверные read/seek аргументы
не двигают cursor; failed reopen закрывает старый decoder. EOF — true/0frames.
inspect_vorbis полностью декодирует фиксированными блоками, сверяет actual/declared frames,
без хранения PCM. Ограничения музыки48000/1..2 проверит importer. Legacy decode меняет out
после закрытия reader, в том числе если encoded input лежит в прежнем out.samples; отказ очищает out.

Две собственные синтетические Ogg fixtures2ch48000/44100 и прежние2mono: exact per-sample
сравнение с old one-shot на той же ОС, блоки1/31/257/1024, seek0/37/1023/last, EOF/refusals/alias.
Release/Debug/ASan+UBSan PASS;4threads×40 open/seek/read/inspect/decode PASS под TSan, включая
instrumented vendor C TU. Actual source mutants в копиях настоящих archives: no-lock→CRC race,
unsafe mono→vendor assert, ignored seek/wrong average→FAIL, early output clear→ASan UAF;
restored binaries PASS. CI Release/Debug/SAN и LinuxTSan подключены.
Types/lint PASS, mono1b54dd84c4e9d75c/stereo24a69db0fc56de9f прежние, RT/gain/limiter/device26
и actual asset→decode→mix seam PASS. audio_core compile iOSsim/Androidx86_64 PASS; на них
декодер не запускался. Ogg manifest import/export audio_core/stream worker — ещё следующие единицы.

## В6в4: worker и transport

Внутренние MusicWorker/MusicTransport пока без публичного MusicStream/Mixer hook.
Cold init копирует до4096 записей каталога, валидирует все источники одним временным decoder;
bytes по-прежнему заимствованы до stop/join. После init только worker владеет двумя decoder slots.
Один RT producer ставит POD load/stop в SPSC16, worker coalesce до последнего запроса на слот.
Поколения не переиспользуются; duplicate текущего tag идемпотентен. Full request queue возвращает
false, RT обязан хранить pending. Expected tag устанавливается до публикации запроса.

Pump не ждёт места/команд: один bounded drain и по одному partial push каждого слота. Остаток
1024-кадрового блока хранит offset; занятое кольцо не теряет и не декодирует этот хвост заново.
Ready(tag) — ≥12000 суммарно опубликованных кадров поколения, не текущая occupancy. Priming RT
кэширует максимум первый matching frame и ждёт ready; stop ready — только ack без PCM.
Read/open failure закрывает лишь свой слот, ready0/failed(tag64), ошибочный блок не публикуется.
Closed atomic работает при full queue/rings/paused callback; ack не ждётся, повторное закрытие
не уменьшает live ниже0. Transport живёт дольше worker destructor и обоих владельцев ring.
