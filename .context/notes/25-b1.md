## Перепаковка листов Puffolotti (В1а)

Разовый скрипт вне дерева, в репозиторий не входит. Повторить при смене кадров:

1. PNG RGBA8 без интерлейса декодируется целиком (фильтры 0–4).
2. Из JSON берутся только прямоугольники `frame` (кадры уже обрезаны: `spriteSourceSize` и
   `sourceSize` не трогаются, пивот низ-центр не сдвигается).
3. Кадры сортируются по высоте, затем ширине, затем исходному порядку; раскладка полками слева
   направо, отступ 1 px между кадрами и полками.
4. Ширина листа перебирается от самого широкого кадра до 2048 с шагом 4; выбирается минимум
   площади, при равенстве — меньшая наибольшая сторона; высота > 2048 отбрасывается.
5. Пиксели копируются построчно; PNG пишется с адаптивным фильтром на строку (минимум суммы
   абсолютных значений), zlib 9.
6. В JSON меняются только `frame.x/y` и `meta.size` (`meta.image` то же имя); `json.dumps(indent=1)` + LF.

Проверка: каждая строка каждого кадра совпала с исходником, перекрытий нет, число непрозрачных
пикселей листа равно исходному. После — `check_asset_licenses.py --write` (sha256 → NOTICES),
`check_sdk_game.sh` (новый хеш в `bundle.hash`, `sdk_game_lib.sh`, `owner-setup.txt`,
`owner-verification.md` §19 и §20, `.context/gates/sdk-game.md`).
