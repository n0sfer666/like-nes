# #26 В5 — строки и UI

## В5а1: таблицы строк

`framework_ui` содержит reader/baker LNST v1 и literal TSV с точными колонками key/en/ru.
Пустой ru печётся как en и учитывается в fallbacks; strict отказывает. Явный одинаковый перевод
откатом не считается. Каждый кодпоинт обеих строк проверяется по named FontSrc, включая ключи
алфавитов grid.*; ошибка называет ключ и U+XXXX. Ключи ASCII letters/digits/_.-, до128 байт,
ID — общий FNV, порядок строк канонический. Дубликаты и совпавшие ID отказываются.

Reader zero-copy, буфер должен быть выровнен и оставаться неизменным. Проверяются envelope,
UTF-8, offsets/lengths/terminators, hashes, строгий порядок ID и число откатов. До4096 ключей,
до16MiB входного TSV и готового blob. Budget baker считает дедуплицированный результат.
Shared 1MiB values проверяются один раз: фиксированный stack workspace, без heap в open/find.
SDK экспортирует только публичные strings.hpp/format/bake; приватные fixtures/indexed stage — нет.

CI запускает оба unit-теста в Release/Debug/ASan. Fuzz strings добавлен последним: index20,
21 целей с IDE,20 без него; старые индексы сохранены. SDK fixture печёт и читает строгую таблицу
против установленного префикса, включая линковку на мобильных платформах.

## В5а2: assetc

`strings|name|tsv|path.tsv|font` разрешает ссылку на font независимо от порядка записей.
Бейк собирает named Raw/Mmap LNST и включает TSV/font в depfile; сводка печатает keys/fallbacks.
`--strict` в общем manifest mode доступен и инструментам игры. Значение scalar flag не может
поглотить следующий --flag. `like_nes_bake` добавляет strict в Release/RelWithDebInfo/MinSizeRel;
Debug допускает counted fallback. COMMAND_EXPAND_LISTS убирает пустой conditional argument.
Грамматика встроенных записей отделена в manifest_shapes; общий список остаётся единым для
parse/kinds_ok/диагностики. Public Record получил font, Bake — strict; private helpers не в SDK.

## В5б1: отдельный UI-ввод

UiInputChannel копирует bounded layout из настоящего пресета ui вне кадра и больше не зависит
от lifetime PresetTable. Семь named actions, необязательные x/y, максимум256 bindings до
выделения layout. Все8 connected pads и клавиатура вместе, без PlayerAssign/consumption/drain;
InputEngine дренирует игру один раз, UI читает её DeviceState. Paired x/y — radial, иначе axial;
определяющая x shape при двух pair declarations. Чужая pair за пределами UI x/y отказывается.
Навигация/erase repeat350/90ms, accept/back edges. Cancel/overflow блокирует удержанные actions
и axes до отпускания, включая opposing axes с нулевой суммой: pos/neg каждой строки и альтернативы
одного устройства учитываются до вычитания/суммы и отпускаются в deadzone. Source raw clamped до sign, также
для INT_MIN и инвертированного источника. KBD Latin edges и Native Unicode — разные режимы;
Native отбрасывает invalid/control scalars. Full intptr pointer IDs, zone pixels, fixed16events/
64codepoints, invalid/overflow cancels. read/cancel zero heap.

SDK fixture конфигурирует channel из baked UI preset и читает настоящий InputEngine после drain.
CI запускает framework_ui_input_test в Release/Debug/ASan с точным ожидаемым вердиктом.

## В5б2: Context и квады

Context init берёт заимствованные immutable buffers Strings/FontTable по named font;
reader objects можно освободить. Fixed128widgets/2048quads/512runs, textprefix256codepoints,
field NULscan1025bytes. begin→button/list/slider/field→end возвращает spans до begin/init/destroy.
UiView задаёт zone w/h≤32767, integer k1..64 и origin. Source/UV обрезаются до scale.
Id FNV(parent,keylen,key,index), весьu64 включая0. Duplicate IDs/invalidrect отказываются,
missinglabel/offscreen/недорисованный widget disabled; slider rollback при quad overflow.
Статические подписи — Strings, field только показывает callerbuffer и возвращает активацию.
Slider меняет value только от ввода уже известного предыдущему кадру widget, без нормализации
данных при рисовании/cancel. Pointer target из предыдущего end, primary capture, release inside
zone, disabled painted overlay blocks click-through. End чинит focus и цвет панели в том же кадре.
Глобальный back остаётся у игры; modal overlays — отдельный Context либо disabled underlying.

Quad/QuadRun перенесены layout-equivalent в render/quad_types.hpp; render_types INTERFACE
экспортирует только CPU types. framework_ui не зависит от renderer/GPU. SDK fixture реально
печёт font, init Context, строит3quads/1run и активирует кнопку через UiInputChannel+InputEngine.
CI: Release loop, отдельный UI Debug step и exact SAN registry для всех5UItests.
Numeric quad/focus golden2a01d5ac8d6063b0, id9dd49e545e8d6500 подтверждены независимым Python
LEstruct/FNV oracle. CPUpreview с настоящим Monogram — build-sdk-work/v5b2-preview/preview.png.
Живой layer GPU golden недоступен: no suitable adapter. Его FAIL не объявляется PASS;
backend text-quads compatibility CPU test проходит.

Следующий шаг: glyph_grid и гейт видимых литералов. Async-интервью B-grid pending:
A добавляет/B закрывает + отдельное erase или A добавляет/B стирает + отдельное Done.
В5 целиком ещё не завершена. Экраны пилота относятся к #29.

## В5б3: UTF-8 сетка ввода

Context::glyph_grid берёт alphabet_key из Strings и callerbuffer; алфавит до126 уникальных
печатных scalars плюс ячейки erase/done. max_len считает scalars, bytecapacity с NUL≤1025.
Некорректный/нетерминированный buffer сохраняется без изменений; старый over-limit текст можно
стирать. Ввод символов точно по алфавиту, без casefold. Erase удаляет целый UTF-8 scalar.
Навигация x/y — по матрице с клампом последней неполной строки. ID включает codepoint,
поэтому перевод/перестановка не превращает старую A в новый символ.

Input requires previous finished enabled grid cell (обычная button с тем же ID не годится).
Сетка целиком в зоне; нехватка widgets отказывает до регистрации, quad overflow отключает все
ячейки и запрещает изменение данных. Cancel/viewchange suppress editing, ноль heap за кадр.
Back возвращается сеткой и потребляет end().back, сохраняет buffer; done тоже завершает без
изменений. Оба имеют приоритет над erase/text. UI preset может назначать B на back или erase:
игровая политика пока не выбрана. Optional action done (например pad:start) — edge с cancel,
семь прежних mandatory actions сохраняются.

SDK fixture вводит A через настоящий InputEngine→UiInputChannel→glyph_grid из установленного
префикса. CI добавляет happy/limits Release/Debug/SAN, включая exact SAN verdicts.
Повторный grid parent в кадре отказывается даже с другим alphabet_key: иначе matrix navigation
могла переходить в чужую сетку. Regression и независимый production harness подтверждают отказ
дубликата и переход IP0→IP1 внутри второй отдельной сетки.
