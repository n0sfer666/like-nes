Принято без вопроса (владелец может развернуть до кода подкоммита):

- `InputEngine` разбирает очередь один раз за тик (`drain`), затем `resolve(tick, player)` на
  каждого игрока. `begin_tick(tick, 0)` = `drain` + `resolve` — игрок 0 и голдены #14 бит-в-бит.
- Контекстный стек общий, биндинги и `prev_held` — на игрока; файл профиля `RebindStore` — свой
  у каждого игрока.
- «Нажми кнопку, чтобы войти» в прототипе — надпись поверх уровня, без отдельной сцены (сцены —
  В7). Игрок 1 на клавиатуре в игре с первого тика, игрок 2 входит посреди уровня.
- `present` и назначенный слот — в снапшоте и хеше; вход посреди уровня воспроизводится реплеем.
