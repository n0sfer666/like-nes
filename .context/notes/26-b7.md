## Независимая предпосылка: вывод SDK

MusicStream/Mixer уже поставляются, MiniaudioDevice ранее отсутствовал в SDK. Reviewed plan
v7-audio-output-plan.md в текущей task state: optional like-nes::audio_device + device.hpp при
AUDIO_MINIAUDIO=ON, engine default без дополнительной зависимости. Vendor include PRIVATE;
null RenderFn отказывается до открытия backend, null user разрешён.

Проверка audio_music_device_test использует только публичные заголовки: actual Ogg в worker,
настоящие miniaudio null callbacks обоих Mixer backend, nonzero PCM, Stream close/join при
живом устройстве, source free после join, тишина после хвоста limiter. Device.stop до Mixer/
user-data. Тот же source копируется в installed-prefix fixture R/D; mobile проверяет actual
archive cross-link без запуска чужой архитектуры. OFF проверяется свежим configure-only;
это не утверждение installed-OFF runtime. Legacy26cases, полностью инструментированные
C/CXX SAN/TSan, types/lint, SDK и exact staged review обязательны до коммита.

Стенд должен связать музыку, существующее меню#25, настоящий тач, save_ms реальной SDK-записи
и rendering. CPU-only вывод не закрывает телефонный FPS. Весь #26/roadmap пока не завершён.

Первый actual callback прогон и повторные Release/SAN/TSan плюс legacy26cases PASS.
Строгий sdk-genre обнаружил недопустимый list(APPEND SDK_HEADERS): static inventory теперь
содержит весь superset API, OFF установка фильтрует device.hpp в HEADER_PATHS. Gate не ослаблен.
Потребители SDK audio вызывают существующий like_nes_add_game для static MSVC CRT.
OFF configure повторно использует только source dirs FetchContent, собственные dependency builds.
Финальные installed-prefix fixtures/types/lint и независимое review ещё обязательны.
