## Packet1: collector и JSON verdict

Generic FrameStats в framework_core: capacity cold, record без heap, interval0 исключает cadence,
work0 допустим, summary сортирует отдельно. Nearest60Hz half-up через quotient/remainder;
miss rate=misses/(intervals+misses). Upper quantiles соответствуют прежнему resimbench.
Capacity/empty/uninitialized capture incomplete; invalid init сохраняет старый capture.
Строгий JSON schema1 +actualCLI selftest123: requiredfields/types/counts/quantiles/save/complete,
duplicate/missing/NaN/Infinity/multiple reports reject. --budget строго <1%, без новых порогов
work-p99/underruns. Метрика сами часы не читает, реальный стенд остаётся packet2.

Main исправил неверные expected values первоначальной Luna fixture: sorted1..100 upper median51,
p99=100; сумма11boundary misses67. Production formula сохранена и сравнивается с независимым
Fraction oracle (11границ +10000u64). До утверждения результата обязательны compiled unit/RT,
actual source mutants, R/D/SAN/GCC/SDK/types/lint и exact staged independent review.

Independent P2 review found implicit vector copy/move could lose reserved capacity while retaining
initialized state: actual probe observed2 hot allocations. FrameStats now explicitly noncopyable/
nonmovable, cold init in place; four type_traits regressions prevent this contract leak.

## Packet2a: отдельный бандл для стенда

`like_nes_bake` принимает несколько вызовов для одной цели. Десктопная цель `<цель>_bundle`
собирает все выходы, мобильная упаковка использует существующий список ресурсов. Каждый
манифест и depfile управляет своим выходом. Фикстура установленного SDK проверяет независимую
пересборку второго выхода и отказы при пересечении имён. Это позволяет вынести музыку стенда
в отдельный бандл без изменения основного игрового манифеста.
