# Спека #25, В5 — состояние раунда

Решения владельца 2026-10-10 (до кода):

- Прототип — **два режима**. По умолчанию Neon Rumble как в В4: adler-манекен, headless-сценарий,
  его строки и хеши, окна §22–§29 не меняются. Волна ИИ — флагом `--wave`, со своим вторым
  headless-сценарием и своим окном §30.
- Враг **без жетона держит кольцо**: подходит на дистанцию ожидания и смещается по `z`, уходя с
  линии цели; с жетоном сближается и бьёт.
- Волна зачищена — **новая через паузу** (~120 тиков) на тех же спавнах. Настоящие волны и арены —
  В6.

Принято без вопроса (владелец может развернуть до кода подкоммита):

- Враги — три копии adler: у него полный список ударов, своих листов врагов ещё нет.
- Цель — ближайший живой игрок (`|dx| + |dz|`), при равенстве — меньшее место; цель без тела
  фреймворк сбрасывает.
- Жетоны: ёмкость — таблица по числу игроков в данных игры (1 → 1, 2 → 2), выбор сложности — #26;
  таймаут 90 тиков от взятия. Тело, пропавшее из пула (KO), теряет мозг и жетон в шаге ИИ.
- Враг с hp 0 снимается игрой, как и игрок; игрока `step_seats` ставит заново.
- Счётчик стоимости ресима: число переигранных тиков у `rollback::Session` уже есть, гейт ресима
  печатает его и время шага ресима. В F3 он появится, когда игра пойдёт через `Session` (#27): в
  хотсите откатываться нечему, и строка F3 показывала бы ноль. В бенче — В9.

Подкоммиты:

  снапшот с таблицей полей; гейт ресима 8 тиков через `Session` на драке с ИИ; сломанные фикстуры —
  ГСЧ вне снапшота, двойное освобождение жетона. Мутанты (8) убиты: освобождение чужого держателя,
  жетон снятого мозга, таймаут ±1, мозги вне порядка, хеш без ГСЧ, таймер после состояния, цель без
  тела, ёмкость; после ревью — однопроходный `step_ai` (жетон мёртвого держателя с большим seq не
