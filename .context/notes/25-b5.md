# Спека #25, В5 — состояние раунда

Решения владельца 2026-10-10 (до кода):

- Прототип — **два режима**. По умолчанию Neon Rumble как в В4: adler-манекен, headless-сценарий,
  его строки и хеши, окна §22–§29 не меняются. Волна ИИ — флагом `--wave`, со своим вторым
  headless-сценарием и своим окном §30.
- Враг **без жетона держит кольцо**: подходит на дистанцию ожидания и смещается по `z`, уходя с
  линии цели; с жетоном сближается и бьёт.
- Волна зачищена — **новая через паузу** (~120 тиков) на тех же спавнах. Настоящие волны и арены —
  В6.

Принято без вопроса (владелец может развернуть до кода подкоммита):

- Враги — три копии adler: у него полный список ударов, своих листов врагов ещё нет.
- Цель — ближайший живой игрок (`|dx| + |dz|`), при равенстве — меньшее место; цель без тела
  фреймворк сбрасывает.
- Жетоны: ёмкость — таблица по числу игроков в данных игры (1 → 1, 2 → 2), выбор сложности — #26;
  таймаут 90 тиков от взятия. Тело, пропавшее из пула (KO), теряет мозг и жетон в шаге ИИ.
- Враг с hp 0 снимается игрой, как и игрок; игрока `step_seats` ставит заново.
- Счётчик стоимости ресима: число переигранных тиков у `rollback::Session` уже есть, гейт ресима
  печатает его и время шага ресима. В F3 он появится, когда игра пойдёт через `Session` (#27): в
  хотсите откатываться нечему, и строка F3 показывала бы ноль. В бенче — В9.

Подкоммиты:

- [x] В5а — `framework::ai`: `WorldRng`, `AttackTokens`, `Brains` и `step_ai` по `seq`, хеш и
  снапшот с таблицей полей; гейт ресима 8 тиков через `Session` на драке с ИИ; сломанные фикстуры —
  ГСЧ вне снапшота, двойное освобождение жетона. Мутанты (8) убиты: освобождение чужого держателя,
  жетон снятого мозга, таймаут ±1, мозги вне порядка, хеш без ГСЧ, таймер после состояния, цель без
  тела, ёмкость; после ревью — однопроходный `step_ai` (жетон мёртвого держателя с большим seq не
  достаётся живому в том же шаге) и снятая защита слота команд. Ресим: 138 откатов / 1053
  переигранных тика, ≈0.6 мкс на шаг (M-серия). Исход боя прибит `ai fight hash` (Release × 3 ОС и
  Debug); забытое поле судится хешем мира без `ai_hash` — игрушечный ИИ тянет ГСЧ на каждом шаге
  подхода, враги с hp 90 дерутся весь прогон, два жетона освобождает снятие мозга.
- [x] В5б — Neon Rumble `--wave`: три adler с `framework_ai` из префикса SDK (кольцо по `seq`, жетон,
  jab), новая волна через 120 тиков, второй headless-прогон гейта sdk-game на 1980 тиков: ИИ дважды
  доводит P1 до hp 0, `step_seats` ставит тело заново (`banderas#5`, `#6`), бот P1 зачищает волну
  к 1846, вторая — на 1966. Режим по умолчанию байт-в-байт. Без вопроса: строй волны — смещения от
  спавна adler; `Mind` получил `world` (удар по имени `jab` из таблицы вида); дальность кольца по
  `seq % 3` — иначе двое ждущих одной чётности вставали в одну точку. Попутно в движке
  `HitEvent::kept`: в размене реакция того же тика обнуляет `struck` атакующего, и отчёт терял
  удар, сделавший нокаут (тик 1845); тесты в `framework_brawl_hit_test` (размен, отброшенный удар)
  и `framework_brawl_clash_test` (разорванный захват). После ревью: цель — `ai::nearest_body`
  (`ai_target.hpp`, в SDK; при равенстве меньший `kind` = меньшее место, unit-тест и мутант в
  `framework_ai_test`), мозг пересчитывает её каждый тик кольца, в сближении держит; бот P1 зовёт
  её же (`rumble_steer` — общий `toward`). Мутанты волны (6) убиты.
- [x] В5в — итог: В5 закрыт 2026-10-10, PR раунда `dev` → `main`. CI зелёный на трёх ОС на
  `e88206d` (build+determinism и sdk+game × 3, crossplay). Гейт зонтика «ресим отката = прямой прогон
  с ИИ» закрыт `framework_ai_resim_test`. Слепое пятно В4г закрыто: в headless `--wave` ИИ дважды
  доводит P1 до hp 0, игра снимает тело, `step_seats` ставит новое (`banderas#5`, `#6`). Окно §30
  (гейт 10 #25: кольцо, жетон, нокаут, новая волна) — у владельца, как и §22–§29; мерж раунда не
  блокирует. Стоимость ресима в F3 — с #27, в бенче — В9.
