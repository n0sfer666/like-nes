## В5а — решения по ходу

- Цель `framework_tiled` (`engine/framework/tilemap/tiled/`) вне SDK: тянет `framework_json`, которого
  в SDK нет. Читатели `LNVL`/`LNOB` — в `framework_tilemap` (SDK), в список заголовков SDK — в В5б.
- Файлы Tiled читает НЕ движок: интерфейс `TiledSource` (тайлсет `.tsj`, картинка → guid текстуры и
  размер). `assetc` резолвит пути (лексический `..` внутри каталога манифеста, точный регистр) и
  пишет depfile.
- Картинка тайлсета / image-слоя обязана быть записью `texture` манифеста (по нормализованному пути):
  кодек выбирает автор, тихого `pixel` нет. Нет записи — отказ с готовой строкой манифеста.
  Размер PNG сверяется с `imagewidth`/`imageheight` тайлсета.
- Секции на бандл — по одной: guid `tilemap` (LNTM), `visual` (LNVL), `objects` (LNOB), записи по
  картам с именем записи манифеста. Эти три имени для `texture` зарезервированы.
- Слой коллизий: `origin` = смещение слоя (группы складываются), `tile_size` = `tilewidth`.
  `visible:false` у слоя коллизий не мешает печати коллизий (только видимой копии).
  Параллакс ≠ 1 у слоя коллизий и у объектного слоя — отказ (мир, а не декор).
- Тайлсет с размером тайла ≠ размеру тайла карты — отказ.
- Порядок слоёв `LNVL` = порядок записей (снизу вверх), отдельного поля нет.
- `LNOB`: объекты отсортированы по (класс, id) — `objects_of_class` отдаёт непрерывный span.
- Помощник Int→fix32: `json::as_fix(node, out)`.
- Объекты печатаются независимо от `visible` слоя: это данные мира, а не декор.
- Доп. отказы сверх спеки: `tileoffset`, `transparentcolor`, `.tsx`, `template`, `rotation`,
  ellipse/polyline/text/gid, свойства color/file/object/class. Ошибка geometry указывает на поле.
- `push_table` — свой файл `push_table.cpp` в `assetc_bake` (нужен и `assetc`, и уровням); бейк двухпроходный (уровни, затем секции).
- Фикстура перебейка `sdk-game`: `sleep 2` вместо отметки из будущего (будущий mtime делает файл
  «новее» навсегда и маскирует следующие раунды); раунд PNG без уровня — тайлсет сверяет размер.
- Вердикты тестов — kebab-case (`framework-tiled: PASS`): регексп CI `^([a-z][a-z0-9-]*: )?PASS`.
- Мутант `+500` в `ticks_from_ms` выживал на 100/250 мс (делятся нацело) → фикстура 260 мс → 16 тиков.
- Owner-verification §18 = гейт 3 спеки #24 (Tiled-пересохранение, хеш 0xf28a379fc38c0753); В5б
  дописывает в него оконную половину.

## В5б — сделано (2026-10-02)

Итог — спека, раздел «Реализация В5б». Решения по ходу:

- Голдены GPU-пути — `framework_layer_golden` в дереве (offscreen RGBA8, точное сравнение с
  CPU-эталоном на Metal/lavapipe/WARP); игру в `sdk-game` судит headless-сводка, окно — владелец (§18
  шаг 5). Числа спрайтов в сводке не пинятся, нули отказов — пинятся.
- Свизл tint белым tint не ловится → в сцене голдена слой с opacity 0; эталон пропускает спрайт с
  нулевой альфой tint.
- `asset_view` отделён от `asset_core`: игре против SDK не нужен zstd ради чтения Raw-записей.
- Порядок текстур игры = порядок guid тайлсетов, затем image-слоёв карты (`Level::guids`) — он же
  номер материала в `draw_layer` и порядок `add_texture`.
- Зум окна — наибольший целый, при котором высота карты влезает в кадр; полный вьюпорт спеки
  (кламп 576×312, заливка фоном, `bounds`) — В7/В8.
- Ревью (3 medium, 10 low — все исправлены): sRGB-поверхность Vulkan/DX12 кодировала тексели PNG
  второй раз → `quad_texel_format`, контроль голдена на `RGBA8UnormSrgb`; повтор слоя на мелком зуме
  — отказ клетки уже пикселя и обрыв по полному списку (`truncated`); перестановка margin/spacing
  была невидима тесту текселей. Риск CI: точность sRGB-кругового пути на lavapipe/WARP.
