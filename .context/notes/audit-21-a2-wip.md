Вторая половина A·2·3 (потолок РАЗМЕРА файла) закрыта отдельным коммитом, как решил владелец:
`platform::read_bytes_capped` в шве + `MAX_TICKS = 480000` / `MAX_FILE` у читателя И писателя
реплея. Потолок назван в тиках, чтобы граница была ЗАКОННЫМ файлом — иначе гейту нечего утверждать
о самом крае; писатель сверяет его БАЙТАМИ (`bytes_for`), потому что тиковая проверка совпадает с
байтовой только при ширине 1. Потолки выделения вынесены в свою цель
`game_platformer_replay_ceiling_test` (разрез — решение владельца, жёсткий лимит длины).

потребителям, решение владельца не запрашивалось. Сообщить после среза.

### A·2·7 — вердикт о версии ABI в разборе манифеста

Решение владельца: `parse_manifest` сверяет `api=` с `PLUGIN_API_VERSION`, гейт `abi()` в
`host.cpp:63` остаётся. Проверка стоит там же, где поле разбирается: это единственное место, где
«до dlopen» держится по построению, а не по дисциплине вызывающего. Поле разбиралось и
выбрасывалось — читатель видел объявленную версию и принимал её за работающую проверку.

Развилки, закрытые интервью по двум кругам ревью:

- переполнение `std::stoi` получило СВОЮ причину отказа: цифры, не влезшие в `int`, — это число, и
  звать их «не числом» значит посылать владельца файла искать опечатку там, где её нет;
- вторая строка `plugin` и повторный ключ `api=` — отказ, а не «побеждает последний»: молчаливое
  правило приоритета обходило вердикт одной лишней строкой.

Находка второго круга, которую не поймал первый: `ls >> m.id >> m.version` съедал первый
`key=value`, если поля версии в строке нет, — `plugin id api=1 api=2` принимался как версия 2, и до
счёта повторов доезжал один ключ. Ключи снимаются со строки независимо от позиции; `Manifest::version`
в дереве не читает никто, радиус ограничен `id` и `api_version`.

Фикстур одиннадцать вместо двух: причин отказа шесть, и каждая чинится по-своему.
`empty_api` пинит кавычки вокруг значения, `overflow` — единственный вход в `catch` вокруг
`std::stoi` во всём дереве, `dup_plugin` несёт ЧУЖУЮ версию (так наблюдаем порядок причин),
`dup_api` — без поля версии (так наблюдаем разбор строки идентичности), `no_panels` держит ранний
структурный выход, `api_typo` — форму, которую разбор не читает.

### Неваккуумность A·2·7

| мутация | что покраснело |
|---|---|
| вердикт о версии убран целиком (поведение до A·2·7) | 17 из 21 |
| ранний структурный выход убран | `a manifest with an identity but no panels is refused` |
| ветка дубля перенесена в конец цепочки | `and a doubled identity is said BEFORE the version…` + 3 |
| позиционные поля снова снимаются до ключей (прежний обход) | `a manifest that names api= twice on one line is refused` + 2 |
| переполнение слито с «не число» | `and a number too big is not called 'not a number'…` |
| кавычки вокруг значения убраны | `…quotes included`, `…instead of trailing off after the colon` |
| найденный токен больше не цитируется | `and the refusal quotes the token it did find…` |
| вторая строка `plugin` терпится | `and a doubled identity is said BEFORE the version…` |
| повторный `api=` терпится | `a manifest that names api= twice on one line is refused` + 2 |
| путь убран из новых текстов | `every refusal names the file it is talking about` |
| `!=` ослаблено до `>` | `a manifest declaring a foreign api version is refused` + 2 |

Блэст-радиус правила о дубле: в дереве нет ни одного манифеста с двумя строками `plugin` или
повторным `api=`, кроме новых фикстур; манифест-врезок в `docs/` и `scripts/` нет; производственный
потребитель `parse_manifest` один — `engine/plugin/ui_shell_main.cpp:60`, он читает `ok` и печатает
`error`. Живые `inspector`/`console` подняты до `api=2` и принимаются.

Шаг ASan/UBSan теперь ассертит СТРОКУ, а не только код возврата, и зовёт гейт с
`UBSAN_OPTIONS=halt_on_error=1`: до этого отчёт санитайзера на новом пути через `catch` печатался бы
в stderr мимо `tee` и оставлял шаг зелёным.
