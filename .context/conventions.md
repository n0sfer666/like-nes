# Конвенции кода

Источник правды по стилю для этого репозитория. Всё ниже — описание того, как код уже написан,
а не пожелание на будущее: расхождение файла с этим документом — дефект одного из двух.
Автоформаттера в дереве нет намеренно (`.clang-format` отсутствует), поэтому правила держатся
ревью — и потому сформулированы явно.

## Язык

- **Комментарии — по-русски**, идентификаторы, строки логов и сообщения об ошибках — по-английски.
- Исходники — **UTF-8 без BOM**. На MSVC это держится `/utf-8` в корневом `CMakeLists.txt`:
  без него компилятор читает файл в системной ANSI-кодировке и молча портит кириллицу.
- Коммиты — по-английски, conventional commits (`feat(scope): …`), без AI-подписей.

## C++

- Стандарт — **C++20**, `CMAKE_CXX_STANDARD_REQUIRED ON`. Компиляторы: MSVC (Windows, основной),
  clang/AppleClang (macOS), gcc/clang (Linux); clang-cl — только для санитайзеров.
- **Без `as`-подобных срезок типов:** C-style касты запрещены, только `static_cast`/
  `reinterpret_cast` с обоснованием в комментарии. `reinterpret_cast` легитимен на границе с C-API
  (Win32-хендлы, `GetProcAddress`), больше нигде.
- **Фиксированная точка вместо float в sim.** Всё, что попадает в golden-хеш, считается на `fix32`
  и целых: float даёт разный результат на разных ОС/архитектурах и ломает инвариант
  «хеш совпадает бит-в-бит на трёх ОС».
- Ширина типов явная: `uint32_t`/`int64_t`/`size_t`. `long` в дереве не использовать — на Win64
  он 32-битный (LLP64), и код, переносимый по чтению, ломается на файлах больше 2 ГБ.
- Владение ресурсами — RAII (`Module`, `Child`, `MappedFile`): move-only, деструктор освобождает.
- Ошибки — кодами возврата (`bool` + out-параметр), не исключениями. Диагностика — в `stderr`
  либо в `last_error()` шва.
- Внутренние помощники TU — в анонимном `namespace`, а не `static`.

## Файлы и границы

- **200 строк — мягкий лимит, 250 — жёсткий.** Одна ответственность на файл.
- Заголовки — `#pragma once`. Порядок включений: свой заголовок → системные → проектные.
- **Платформенный код живёт ТОЛЬКО в `engine/platform/*`** (ADR 0012). Реализацию выбирает CMake
  парой `*_posix.cpp`/`*_win32.cpp`; OS-`#ifdef` вне шва проверяется грепом в CI до сборки.
  Новая платформенная ручка проектируется как интерфейс в `platform_*.hpp`, а не как ветка
  в существующем файле.
- Файловый ввод-вывод — через `platform::open_file`/`read_text`/`read_bytes`/`remove_file`,
  а не `std::fopen`/`std::remove`: узкие CRT-функции на Windows идут через ANSI-кодовую страницу
  и не открывают путь через профиль `C:\Users\Пётр\`.

## Комментарии

Комментируется **почему**, а не **что**. Ценность комментария в этом дереве — зафиксировать
причину, которую иначе восстановит только тот, кто снова наступит на грабли: контракт платформенного
API, порядок шагов, который единственно работает, причину, по которой альтернатива отвергнута.
Комментарий-пересказ соседней строки — шум и подлежит удалению.

## CMake

- Цели объявляют свои зависимости через `target_link_libraries`; `PUBLIC` — если зависимость видна
  в заголовке цели, иначе `PRIVATE`.
- Прямую зависимость, которая уже приходит транзитивно, повторно не объявлять: CMake дедуплицирует
  прямой список, но транзитивное замыкание дописывает после него, и библиотека попадает на
  линкер-строку дважды.
- Опции сборки — `option()` с осмысленным дефолтом; в headless-CI выключаются флагом, а не
  условной компиляцией.

## Тесты и гейты

- Тест печатает `PASS`/`FAIL` в stdout и возвращает код выхода; CI ассертит **строку**, а не
  только код. Golden-хеш печатается в лог, чтобы расхождение было видно без перезапуска.
- **Ассерт, который не падает на сломанной реализации, ничего не проверяет.** Новый гейт
  проверяется намеренной поломкой кода под ним.
- Гейт либо гоняется на всех трёх ОС, либо шаг CI назван чужим скоупом. Понижение гейта до
  warning (`continue-on-error` на обязательном шаге) запрещено.
