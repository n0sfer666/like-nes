# Переменные окружения

Значений здесь нет и не будет — только имена и назначение.

## Рантайм игры

| Переменная | Назначение |
|---|---|
| `LIKENES_ASSETS` | Каталог ассетов; проверяется первым, до exe-относительных кандидатов. |
| `LIKENES_SAVE_DIR` | Каталог сейвов. По умолчанию — пользовательский каталог данных ОС (`%APPDATA%\like-nes`, `~/Library/Application Support/like-nes`, `$XDG_DATA_HOME/like-nes` или `~/.local/share/like-nes`); фолбэк — рядом с исполняемым. |
| `LIKENES_ACH_PLUGIN` | Путь к плагину-бэкенду достижений (`plugin_steam.so`, `plugin_ach_fake.so`). Пусто → только локальный прогресс. |

## Тестовые ручки (только для гейтов CI и ручных прогонов)

| Переменная | Назначение |
|---|---|
| `ACH_FAKE_OFFLINE=N` | Фейковый бэкенд: первые N вызовов `begin()` возвращают «недоступен» (нет сети) — `Delivery` не подключается и копит очередь. |
| `ACH_FAKE_RETRY=N` | Фейковый бэкенд: N отказов на `unlock`/`set_stat` с повтором. |
| `ACH_FAKE_FATAL=1` | Фейковый бэкенд: фатальный отказ → очередь сбрасывается, бэкенд помечается мёртвым. |
| `ACH_FAKE_REMOTE=A,B` | Ачивки, «уже открытые» на удалённом сервисе, для `poll_remote`. |
| `STEAM_STUB_INIT_FAIL=1` | Контракт-стаб Steamworks: `SteamAPI_Init()` падает (клиент не запущен). |
| `STEAM_STUB_STORE_FAIL=N` | Контракт-стаб: первые N `StoreStats()` возвращают false. |
| `STEAM_STUB_REMOTE=A,B` | Контракт-стаб: ачивки, открытые на сервисе (другая машина). |
| `ASAN_OPTIONS=detect_leaks=0` | Обязательна для ASan-гейта UAF-после-dlclose: статика выгруженной библиотеки видна LSan как утечка без символов. |

## Сборка

`STEAMWORKS_SDK_DIR` — не переменная окружения, а CMake-опция: путь к распакованному Steamworks SDK.
Задан → `plugin_steam` линкуется с настоящим `libsteam_api` (`LIKE_NES_STEAM_SDK`), иначе с
контракт-стабом. SDK в репозиторий не вендорится.

`PLUGIN_FORCE_DLCLOSE` — не переменная окружения, а define компилятора (`-DPLUGIN_FORCE_DLCLOSE`).
Под ASan `host.cpp` по умолчанию не зовёт `dlclose` (иначе теряются символы), и сценарий
use-after-free для `Delivery`→`Backend` не воспроизводится вовсе. Гейт собирается с этим define.
