## Ядро

| Аспект | Выбор | Обоснование |
|---|---|---|
| Язык ядра | **C++** | эффективность = Rust, но зрелее экосистема + офиц. консольный SDK |
| Gameplay-язык | C++ напрямую, hot-reload shared-lib | максимальный потолок оптимизации |
| Hot-reload | stateless shared-lib (C-ABI), state в host | безопасный swap функций, ложится на ECS |
| Ядро данных | Archetype ECS (**flecs**) | cache-locality при итерации, C/C++ archetype |
| Планировщик | детерминированный параллельный (фикс. граф) | параллелизм без потери детерминизма |
| Детерминизм | да, fixed timestep + детерм. порядок | rollback/replay/тесты |
| Числа симуляции | fixed-point (сим) / float (рендер) | бит-в-бит кроссплатформенно |
| Память | арены/пулы + per-frame allocator (+ ASan/UBSan) | предсказуемость; safety вручную (нет borrow-checker) |
| Ассеты/диск | кастомный бинформат (target-native, mmap zero-copy) + гибрид mmap/async-стрим + кодек-по-классу | минимум RAM/диск/времени загрузки; дизайн — спека #5, ADR 0003 |
| Рендер | **Dawn (C++ WebGPU)** / wgpu-native | Vulkan/Metal/D3D12/GLES из коробки |
| Ошибки | SEH/сигнал-изоляция на host↔lib границе | live-разработка не падает целиком (сложнее, чем catch_unwind) |
| Toolchain | бандл пиннед C++ (clang+build) + NDK/iOS SDK | воспроизводимые билды, desktop→mobile |
| Консоли | HAL + **офиц. C++ SDK-путь** | риск снят (в отличие от Rust) |

## Целевые платформы (приоритеты уточнены 2026-07-18)

- **Цель №1 (сейчас):** Steam-десктоп — **Linux, macOS, Windows**.
- **Мобилки (Android/iOS):** через адаптеры/самописный слой ИЛИ отложить — НЕ блокируют выбор языка.
- **Консоли:** будущее, через HAL + официальный C++ SDK-путь.
- **Разработка:** только desktop (win/nix/macos).

**Критерий выбора языка:** эффективность КОНЕЧНОГО ПРОДУКТА (макс. охват железа → макс.
игроков). При паритете Rust≈C++ тайбрейк — зрелость экосистемы + консольный путь.
Таргет-аудитория движка — все (соло → студии).
