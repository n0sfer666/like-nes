# Порядок работы: от промпта до листа в движке

[← к пакету](README.md)

Этот файл — пошаговая инструкция. Каждый шаг описан действиями: что открыть, что нажать, что
должно получиться. Подробности и чек-листы приёмки лежат в остальных файлах пакета, ссылка стоит у
шага. Шаги идут строго по порядку, кроме отмеченных «можно параллельно».

Инструменты: ChatGPT Images (рисует), **Pixelorama 1.2.3** (чистит, анимирует, собирает лист) и
любой текстовый редактор (файл `.sheet` с клипами и боксами).

## 0. Подготовка — один раз

1. Скачать Pixelorama 1.2.3: [itch.io](https://orama-interactive.itch.io/pixelorama),
   [Steam](https://store.steampowered.com/app/2779170/Pixelorama/) или
   [GitHub](https://github.com/Orama-Interactive/Pixelorama/releases). Бесплатно, лицензия MIT.
2. Завести рабочую папку вне репозитория, например `pilot-art/`, и в ней:

   ```text
   pilot-art/
     pilot.gpl      копия docs/art/pilot.gpl
     log.txt        журнал генераций (export.md §Лицензия)
     style/         лист стиля
     monk/          всё по монаху: картинки ChatGPT, monk.pxo, monk.png, monk.sheet
     bandit/        то же по рядовому
     village/       фон
   ```

3. Загрузить палитру: перетащить `pilot.gpl` в окно Pixelorama (или **File → Open...**). Она
   появится в списке палитр на панели **Palettes**.
4. Включить сетку пикселей: **View → Show Pixel Grid**. Координаты пикселя под курсором Pixelorama
   показывает в верхней панели. По ним потом снимаются боксы.

## 1. Лист стиля

1. Скопировать промпт из [style-bible.md](style-bible.md) §«Промпт листа стиля» в новый чат
   ChatGPT. Ничего не прикладывать.
2. Проверить картинку по списку «Приёмка» в том же разделе. Если не прошла, повторить запрос по правилам
   дрейфа ([README.md](README.md) §Общие правила дрейфа).
3. Сохранить принятую как `style/style-ref.png`. Её прикладывают ко всем следующим запросам.

## 2. Model sheet персонажей

1. Взять шаблон из [characters.md](characters.md) §«Шаблон промпта model sheet» и вставить в него
   описание монаха из §«Описания для промпта». В приложении `style-ref.png`.
2. Проверить по §«Приёмка model sheet», затем прогнать через **чистку** (шаг 4) и проверить рост:
   у монаха 96 px.
3. То же для рядового 1, рост 104 px. В приложении ещё и принятый model sheet монаха.
4. Сохранить как `monk/model-sheet.png` и `bandit/model-sheet.png`.

## 3. Ключевые позы

1. Открыть таблицу ключей клипа в [clips.md](clips.md). Промпт поз лежит в
   [animation.md](animation.md) §Ключевые позы.
2. Один запрос — один клип, не больше 4 поз. В приложении: model sheet и `style-ref.png`.
3. Каждую принятую картинку сохранить как `monk/keys-<клип>.png`.

## 4. Чистка картинки ChatGPT

Делается с каждой картинкой: model sheet, ключи, фон. Подробно — [export.md](export.md).

1. **File → Open...** — открыть картинку как отдельный проект.
2. **Фон.** Инструмент **Select By Color**, кликнуть по пурпурному фону, **Edit → Delete**,
   **Select → Clear**.
3. **Размер.** **Project → Scale Image**: *Percentage*, замок пропорций, *Interpolation: Bilinear*.
   Процент = целевой рост / рост фигуры на картинке × 100.
4. **Палитра.** Выбрать `pilot` на панели **Palettes**, затем **Effects → Color → Palettize**.
5. **Пиксели.** Почистить контур и мелкие детали карандашом (export.md §Сетка, пункт 3).

## 5. Сборка клипов персонажа

1. **File → New...**: размер **192×192**. Это одна клетка листа.
2. **Project → Color Mode → Indexed**, палитра `pilot`.
3. Создать столько кадров, сколько клеток у персонажа: монах — 60, рядовой — 32. Кнопка
   **Add a new frame** на таймлайне.
4. Кадры идут **в порядке раскладки** из [clips.md](clips.md) §Раскладка листа, а не в порядке
   игры. Каждый клип отметить тегом, чтобы не путаться: правый клик по первому кадру → **New Tag**,
   имя клипа, *From* и *To*. Номер кадра = ряд × 10 + колонка + 1.
5. Ключи из шага 4 вырезать и вставить в свои кадры. Подошвы касаются **нижнего ряда пикселей**,
   центр опоры — по центру клетки (колонка 96).
6. Кадры-повторы (в clips.md рисунок стоит в двух клетках подряд) — правый клик по кадру →
   **Clone Frame**.
7. Промежуточные кадры дорисовать: [animation.md](animation.md) §In-betweens.
8. Сохранить как `monk/monk.pxo` (**File → Save...**).

## 6. Палитры рядового

Три варианта одежды одной сменой тонов: [export.md](export.md) §Рампы. Проверить, что сменные
тона не протекли на кожу и контур.

## 7. Экспорт листа

1. **File → Export...**, вкладка **Spritesheet**.
2. *Frames: All frames*, *Orientation: Rows*, *Columns: 10*, *Layers: Visible layers*,
   *Crop mode: None*, *Resize: 100 %*. *Export JSON data* не нужен.
3. Имя файла: `monk/monk.png`. Лист монаха получается 1920×1152, рядового — 1920×768.

## 8. Файл `.sheet`: клипы, боксы, события

1. Создать `monk/monk.sheet`. Скопировать в него готовые строки `image`, `grid`, `clip` и `event`
   из [clips.md](clips.md) §Раскладка листа.
2. Дописать боксы — по строке на каждый бокс каждой клетки. Как снять координаты, описано в
   [animation.md](animation.md) §Боксы и события.
3. Боксы — самая долгая часть. Одинаковые клетки (повторы и стойка) копируют строки друг друга,
   меняется только номер клетки.

## 9. Проверка бейком

В папке персонажа лежит `monk.manifest` из двух строк:

```text
texture|monk_sheet|pixel|monk.png
clips|monk|sheet|monk.sheet
```

Из корня репозитория, пути — к своей папке `pilot-art/` (на Windows — `build\assetc.exe` и
`build\clip_dump.exe`):

```sh
cmake --build build --target assetc clip_dump
./build/assetc --manifest ~/pilot-art/monk/monk.manifest ~/pilot-art/monk/monk.bundle
./build/clip_dump ~/pilot-art/monk/monk.bundle
```

Ожидаемо: `assetc` печатает `[assetc] manifest ... (… bytes, 2 assets)` и строку `bundle_hash`. `clip_dump` выводит по
строке на клетку, всего 60 у монаха и 32 у рядового:
`monk/strike1 frame=2 boxes=hit0,hurt0,hurt1,push event=-`. По этим строкам видно, какие боксы и
события есть у каждой клетки. Ошибку в `.sheet` бейк называет по строке, например
`box 'hit0' leaves its 192x192 cell; the pivot is at the bottom centre`.

## 10. Фон — можно параллельно с шагами 2–9

Пилот — деревня. Слои — [backgrounds.md](backgrounds.md) §Планы, промпт — §«Промпт плана».
Планы по одному, каждый через чистку (шаг 4). Шов —
[export.md](export.md) §Бесшовный слой. Один PNG на план, бокс и `.sheet` фону не нужны.

## 11. Журнал

Каждый принятый файл — строка в `log.txt` ([export.md](export.md) §Лицензия и журнал генераций).
В движок папка `pilot-art/` попадает в В6 спеки #29, до тех пор она у владельца.
