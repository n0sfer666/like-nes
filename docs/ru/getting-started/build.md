# Сборка

[English](../../en/getting-started/build.md) · Русский

Сначала [системные требования](prerequisites.md) — на Windows из приглашения *x64 Native Tools*.

```sh
git clone https://github.com/n0sfer666/like-nes.git
cd like-nes
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Первая конфигурация выкачивает зависимости, пиннутые в `CMakeLists.txt` (GLFW, flecs, бэкенд
WebGPU, Dear ImGui, …), поэтому ей нужна сеть; последующим — уже нет. Первая полная сборка идёт
минуты, а не секунды, и почти всё это — те самые зависимости, которые дальше не пересобираются.

## Опции, меняющие состав целей

Набор целей задаётся набором опций, а не каталогом сборки. Значения по умолчанию — то, что нужно
для первой сборки; знать стоит вот эти:

| Опция | По умолчанию | Что делает |
|---|---|---|
| `PLUGIN_UI` | `ON` | Редактор (`editor_shell`). Без неё дерево конфигурируется headless, и цели редактора не существует вовсе. |
| `AUDIO_MINIAUDIO` | `ON` | Аудио-бэкенд. `OFF` оставляет аудио-шов движка с молчащим устройством. |
| `PLUGIN_WASM` | `ON` | Хост WebAssembly-плагинов. Нужен C API wasmtime в `deps/`. |
| `IDE_POC` | `ON` | Фундамент редактора: документ сцены, round-trip, undo — и образец `game_platformer`. |
| `LINUX_WAYLAND` | `OFF` | Нативный бэкенд Wayland вместо X11/XWayland. Только Linux. |
| `CMAKE_BUILD_TYPE` | — | Задавайте явно. Незаданный тип на одноконфигурационном генераторе означает отсутствие флагов оптимизации вообще. |

Каталог сборки помнит опции, которыми он сконфигурирован, поэтому смена опций — это
переконфигурация того же каталога (или второй каталог).

## Сборочный гейт

Перед коммитом вместо голой сборки используется гейт — он валится ещё и на предупреждениях, в тех
же настройках, что и CI:

```sh
bash scripts/build_check.sh
```

Код движка собирается с `-Wall -Wextra -Werror` (`/W4 /WX` на MSVC), а сторонние зависимости из
этого исключены намеренно: они пиннуты на коммит, и правка любой из них сломала бы байт-детерминизм,
на котором держится пекарь ассетов. Гейт вдобавок грепает лог сборки, потому что `-Werror`
покрывает только компилятор — драйвер MSVC, линкер и сам CMake сообщают о предупреждениях мимо него.

Зовите его через `bash`, а не по exec-биту: на Windows-раннере оболочка — git-bash, и бит из индекса
он не наследует.
